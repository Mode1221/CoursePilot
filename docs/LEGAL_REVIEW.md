# 법률 준비 현황

코드와 문서로 맞출 수 있는 부분은 반영했다. **전문가 확인이 필요한 항목**이 남아 있다.
처리방침·약관은 코드가 실제로 하는 일과 같아야 한다 — 수집 항목·보관 기간·위탁처를 바꾸는 PR 은 이 문서와
`frontend/src/app/privacy/page.tsx`·`terms/page.tsx` 를 함께 고친다.

  브라우저 저장소) / 보유 기간(탈퇴 즉시, 체험 30일, 카운터 14일, 보상 기록 1년, 로그 용량 순환, 백업 7일) / 파기 /

- **이용약관**(`/terms`): 14조 + 부칙. 무료 서비스와 유료 전환 시 사전 고지·동의, **생성형 AI 이용 고지**(인공지능기본법
  제31조, 2026-01-22 시행 — 화면의 `AiNotice` 표시와 함께), 체험·가입·만 14세, 이용 한도, 초대 보상과 부정 이용,
  장소 정보의 한계, 이용자 입력·공유 링크, 금지 행위, 서비스 중단 30일 전 고지, 책임 제한(고의·중과실 제외), 준거법.
- **동의 문구**: 체험 시작(`/start`)과 카카오 로그인(`/login`)에 약관·처리방침 링크, 만 14세 이상, 생성형 AI 이용,

- **같이 정하기 상대방 고지**: 가입하지 않은 상대가 카드를 쓰는 화면(`/together/[token]`)에 입력값의 용도·삭제 시점·

- **코드를 방침에 맞춤**: 탈퇴 시 행동 기록(카테고리 선호)·같이 정하기 상대별 기록까지 삭제, 초대 보상 기록의 계정
  식별값 즉시 익명화, 1년 지난 보상 기록을 매일 정리(`scripts/purge_guests.py`). 테스트 `tests/test_privacy_retention.py`.

## 운영자 정보
`frontend/src/services/operator.ts` 한 곳만 고치면 처리방침·약관에 반영된다. 운영자·개인정보 보호책임자·연락 메일 기재됨.
- **사업자 등록 여부** — 유료 기능이나 광고 수익을 시작하면 사업자등록·통신판매업 신고와 화면 하단 사업자 정보 표시가
  필요하다(전자상거래법 제10조). 무료 베타 동안은 필요 없다.

## 전문가 확인 필요
1. **국외 이전 동의 방식** — 제28조의8 제1항 제3호(계약 이행에 필요, 처리방침 공개)로 별도 동의 없이 처리한다고 보았다.
   이 해석이 맞는지, 가입 화면 문구가 충분한지.
2. **같이 정하기 상대방 정보** — 가입하지 않은 사람의 호칭·취향을 받는 근거와 고지 방식(현재: 입력 화면 안내 + 별명 권장).
3. **책임 제한 조항**(약관 7·12조) — 약관규제법상 효력 범위.
4. **로그 보관 기준** — 용량 순환(서비스별 30MB) 방식이 안전성 확보조치 기준의 접속기록 보관 의무에 해당하는지
   (개인정보처리시스템 접속기록은 운영자 접속 대상이며 1년 이상 보관 기준이 있다 — 1인 운영 규모에서 적용 범위).
5. **인공지능기본법 고지 충분성** — 생성형 AI 결과물 표시(`AiNotice`)와 약관 3조 고지로 제31조 의무를 다하는지, 시행령 기준.
6. **장소 데이터 이용 조건** — Google Places 캐시 기한·표시 의무(현재 평점 출처 표시, 영업시간 캐시 기간은
   `GOOGLE_HOURS_TTL_DAYS`), 카카오·네이버 API 약관, LOCALDATA 출처 표시.
7. **유료 전환 시** — 전자상거래법 사업자 정보 표시, 포인트·구독 환불 규정, 약관 변경 동의 절차.
8. 위치정보: 현재 기기 위치(GPS)를 받지 않는다. 받게 되면 위치정보법 신고와 동의가 필요하다.
