# 데이터 수집·활용 전략

기준: **콜드스타트에 강한가**(유저 적어도 쌓이나) · **광고/조작에 강한가**.

## A. 암묵적 행동 신호 (수집 마찰 0, 콜드스타트 최강)
1. 장소 채택 수 — 코스에 포함될 때마다 +1 *(구현)*
2. 북마크 수 — 저장된 코스 등장 +2 *(구현)*
3. **생존율** — AI 추천 후 유지 vs 삭제/교체 → 추천 적중 학습 *(구현: 삭제/교체 시 -1로 상쇄)*
4. 교체로 밀려난 장소 = 음의 신호 *(구현)*
5. 공유/열람 수 — 완성도 대리지표(열람 시 약한 가점) *(구현)*
6. 완주 신호("다녀왔어요") — 실제 방문 시 +3 강한 가점 *(구현)*
7. 재정렬 패턴 — 확정 순서의 카테고리 전이 학습 *(구현)*

## B. 명시적 최소마찰 신호 (원탭, 텍스트 아님 → 광고·약관 무관)
8. 완료 후 👍/👎 — 원탭 만족도(±2 가점) *(구현)*  9. 장소별 ⭐ 빠른 평가 *(구현)*  10. 재방문 의사 토글 — 장소 단위 강한 긍정(+2) *(구현)*

## C. 컨텍스트 신호 (개인화 정밀도)
12. 시간대 컨텍스트 — 장소×데이파트(아침/낮/저녁) 채택 학습 *(구현)*
11. 요청 원문 로그  12. 시간대/요일/동행유형  13. 선언 선호 vs 행동 선호 보정 — 채택 카테고리 학습·개인화 가점 *(구현)*  14. 날씨/계절 *(후보)*

## D. 피드백 루프 (품질 자기개선)
15. Best-of-N 후보 노출→선택으로 목적함수 가중치 학습 — 채택 시드 전략 로깅 *(구현)*
16. 조건 완화 수용률 → 하드/소프트 제약 학습 — 수용률로 완화 강도 조절·키워드 소프트드롭 *(구현)*
17. 코스 점수 vs 실제 만족도 회귀로 계수 튜닝 — 예측점수·만족도 대조 데이터 수집 *(구현)*

## E. 외부 정량 (합법·요약 아님)
18. 별점·리뷰 수(Google, 숫자만)  19. 공공데이터(TourAPI)  20. 실시간 혼잡/영업

## 활용(정밀화)
- 시간 감쇠(최신 트렌드), 지역×카테고리 정규화(상대 인기)
- 개인화 벡터(pgvector), 협업 필터링, 콜드스타트 폴백 체인
- 목적함수 계수 A/B 학습

## 구현 순서
1. 생존율/교체 신호 *(본 변경)* — 기존 편집 이벤트에서 공짜 수집
2. 피드백 루프(완화 수용·후보 선택 로깅)
3. 원탭 평가(👍/⭐)
4. 컨텍스트(동행유형) + 시간감쇠·지역정규화
