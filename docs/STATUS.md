# CoursePilot 기능·개발 현황

> 이 문서는 기능 추가/변경 시 함께 갱신한다. 최종 갱신: 2026-09-08

상태 표기
- ✅ 완료 — 구현 + 테스트 + CI 통과 (키 없으면 폴백 동작)
- 🔑 실연동 대기 — 코드 완성, 키 주입 시 활성 (실호출 1~2라운드 검증 필요)
- 🟡 부분/제한
- ⬜ 미착수

## 1. 코어 사용 흐름
- ✅ 코스 생성/조회/공유 링크 (메신저 독립, 읽기전용 공유뷰)
- ✅ 자연어 요청 → 코스 자동 생성
- ✅ 수동 편집(드래그 재정렬·삭제) + 동선 자동 재계산
- ✅ 편집 되돌리기(undo, 삭제한 장소 복원) — `POST /courses/{id}/items`
- ✅ 장소 직접 검색·추가 패널 — `GET /places/search` (AI 질문 미소모)
- ✅ "함께 가요" 추천 장소를 코스에 원탭 추가
- ✅ 완주("다녀왔어요")·만족도(👍/👎)·재방문·별점 원탭

## 2. AI 에이전틱 파이프라인 (7장)
- ✅ 조건 분해(규칙 기반) — 시각/분·반, 예산(만원/원), 동행유형, 키워드
- 🔑 LLM 조건 분해 — Claude Haiku 4.5 (키 없으면 규칙 폴백)
- ✅ 물리 검증(영업시간·브레이크·이동시간), 조건 완화 재시도
- ✅ 완화 수용률 학습 → 완화 강도 자동 조절 + 소프트 키워드 드롭

## 3. 코스 품질 (docs/AI_COURSE_QUALITY.md)
- ✅ 후보 스코어링, 카테고리 시퀀스 템플릿, 동선 최적화(NN), Best-of-N
- ✅ 콜드스타트 폴백(신호 없으면 외부평점 의존)

## 4. 데이터 학습 신호 (docs/DATA_STRATEGY.md) — 전부 ✅
- 채택·북마크·생존율·교체 음의신호
- 완주(+3)·👍/👎·재방문·별점, 공유 열람
- 시간대 컨텍스트, 행동 선호(선언 vs 행동), 재정렬 패턴
- 시간감쇠(EWMA)·카테고리 상대 정규화
- 경량 협업필터링(공동채택), Best-of-N 전략 로깅, 예측점수↔만족도 대조, 관측 엔드포인트

## 5. 실시간·동시편집 (5장)
- ✅ Socket.IO 룸 브로드캐스트, 액션 큐 직렬화 + AI Lock, append-only 채팅 로그

## 6. 회원·과금 (9장)
- ✅ 크레딧(월 무료 + 구매 포인트), 원자적 차감/환불, 레퍼럴 보너스, 온보딩 선호
- 🔑 SMS 인증(NHN Cloud) — 키 없으면 인증 생략
- 🔑 결제 검증(포트원 v1) — 키 없으면 즉시 지급

## 7. 지도·장소
- ✅ 어댑터 레이어(벤더 직접호출 금지 원칙)
- 🔑 네이버 지역검색/길찾기 (키 없으면 Mock)
- 🔑 Google Places 평점 enrich (숫자만, 약관 안전)
- 🔑 프론트 네이버 지도 렌더러 (키 없으면 SVG 폴백)

## 8. 리뷰 데이터 (8장)
- 🟡 Google 리뷰 소스 실구현(숫자·attribution) / 네이버 블로그는 링크만(약관)
- ⬜ 리뷰 RAG 요약 파이프라인 — 약관 제약으로 얕음, 고도화 미착수

## 9. 프론트 UI (4장)
- ✅ 지도+채팅 하이브리드, 타임라인/장소상세 모달, 접근성(포커스 트랩), 연결 배너
- ✅ 마이페이지·공유뷰·온보딩
- ✅ 공유 링크 OG 미리보기(메신저에 코스 제목·동선 요약 노출)

## 10. 인프라·배포
- ✅ DB/pgvector 영속 + 인메모리 폴백, rate limit·요청 로깅
- ✅ CI(ruff/eslint/tsc/pytest/vitest/Playwright)

3. **리뷰 RAG 고도화** (🟡/⬜) — 약관 준수 범위 내 데이터 강화.
